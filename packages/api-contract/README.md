# API contract

`openapi.yaml` is the canonical OpenAPI 3.1 contract for API runtime generation. The TypeScript method/path manifest in `src/generated-routes.ts` is generated from it with `pnpm run generate:routes`; `pnpm run verify:generated` rejects drift.

The contract now specifies endpoint-specific request/response schemas, statuses and error responses, auth/assurance metadata, parameters, and relevant headers for all 70 operations. Structural tests reject route-inventory placeholders and default response schemas. `test-fixtures/http-golden.json` contains synthetic examples for selected cross-cutting wire cases; it is not an exhaustive golden response for every operation. The existing TypeScript handlers and tests remain the behavior oracle, and endpoint-by-endpoint parity and differential coverage must pass before cutover.

Generate Echo v5 strict transport types from `apps/api/oapi-codegen.yaml` with the pinned `oapi-codegen` v2.8.2 generator. The runtime uses the generated `ServerInterface` and models, with the route dispatcher generated from this OpenAPI file. It intentionally passes raw Echo requests to operation handlers instead of using oapi-codegen's parameter-binding wrapper, because that wrapper can validate query parameters before authentication and replace established endpoint-specific errors. Authorization, request validation, application workflows, persistence, and error policy remain handwritten.
