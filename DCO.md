# Developer Certificate of Origin

rhasia-scret accepts contributions under the [MIT License](LICENSE). Each
contributor must certify that they have the right to submit the work and agree
to license it under that license. The project uses the Developer Certificate
of Origin (DCO) version 1.1 rather than a separate CLA.

Contributors certify each commit by adding a `Signed-off-by` trailer with the
same name and email used for the contribution. Git can add it automatically:

```bash
git commit -s
```
