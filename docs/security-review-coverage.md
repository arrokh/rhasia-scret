## Authentication and route inventory

Canonical operations are in [`packages/api-contract/openapi.yaml`](../packages/api-contract/openapi.yaml); generated dispatch and route registration are in [`apps/api/internal/httpapi/router.go`](../apps/api/internal/httpapi/router.go) and `apps/api/internal/httpapi/operations.gen.go`. [`apps/api/internal/app/api/application.go`](../apps/api/internal/app/api/application.go) supplies the identity authorizer to application handlers. The machine-readable [route authorization map](security-review-route-authorization-map.json) maps all 62 in-scope method/path pairs from the 70-operation contract to an actor, final resource decision, source files and regression tests. It names the eight out-of-scope authentication, utility and current-user-profile operations and why they are excluded. The architecture regression checks exact set equality against OpenAPI; this is inventory/link evidence, not proof that every authorization decision is correct.

For application routes, the actor chain is:

1. [`apps/api/internal/httpapi/auth.go`](../apps/api/internal/httpapi/auth.go) supplies request credentials to the session verifier.
2. [`apps/api/internal/repository/identity_session_verifier.go`](../apps/api/internal/repository/identity_session_verifier.go) validates the active session and returns the verified principal.
3. [`apps/api/internal/service/identity_authentication.go`](../apps/api/internal/service/identity_authentication.go) resolves the Application User, active status, assurance and mutation budget.
4. [`apps/api/internal/handler/identity_user_crypto_profile_handlers.go`](../apps/api/internal/handler/identity_user_crypto_profile_handlers.go) exposes `AuthorizeApplicationRequest`; resource handlers pass its returned user ID separately from caller-supplied target IDs.

`GET /v1/internal/retention-purge` is the deliberate exception: [`apps/api/internal/handler/retention_handlers.go`](../apps/api/internal/handler/retention_handlers.go) authorizes a configured system bearer secret rather than an Application User.
