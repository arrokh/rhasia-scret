# User-created vault unlock secret

Superseded by ADR-0060 for new and changed user-authored Vault Unlock Secrets. During Personal Vault setup, the client offers both a randomly generated Vault Unlock Secret (recommended) and a user-created Vault Unlock Secret. A generated secret remains multi-word; the former three-character minimum applied under ADR-0029. New and changed user-authored secrets now require at least twelve trimmed Unicode code points, while existing secrets remain usable for unlock. Both options remain client-only and use the same Argon2id derivation and encrypted storage protocol; the server never receives either secret.
