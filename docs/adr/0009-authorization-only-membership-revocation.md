# Authorization-only membership revocation

Removing a member immediately denies all future application access to the Shared Vault and removes its UI visibility, without automatic key rotation. Hosted Local Vault Snapshots now contain Personal Vault data only, so supported offline access cannot open a Shared Vault after revocation; online Shared Vault material is transient and is evicted on connectivity loss or failed refresh. This client policy does not erase ciphertext, OTPs, or TOTP secrets the member obtained while authorized, and it cannot constrain old clients that remain permanently offline. Owners must reset affected 2FA secrets at their original services for full credential revocation. See ADR-0052.
