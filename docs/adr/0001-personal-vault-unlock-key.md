# Personal vault unlock key

A client derives a Vault Unlock Key from the user's Vault Unlock Secret and uses it to unlock a random User Root Key. The User Root Key protects the Personal Vault Encryption Key and encrypted User Encryption Key Pair; the server stores only wrapped/encrypted material, enabling access from another authenticated browser without being able to decrypt vault contents. A passphrase change re-wraps only the User Root Key, and a forgotten Vault Unlock Secret cannot be reset by the application. After its first unlock, a Remembered Browser holds a browser-local credential that lets its authenticated user unlock the User Root Key without re-entering the Vault Unlock Secret; another browser must be enrolled by entering that secret or using a future recovery flow.
