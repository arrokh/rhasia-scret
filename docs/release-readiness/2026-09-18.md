## Implemented architecture

- `apps/api` is a standalone Hono service with Bun as the primary runtime.
- `apps/api/src/node.ts` and `apps/api/dist/node.js` provide generic Node.js hosting.
- `apps/api/api/[...path].ts` provides the separate Vercel Node.js adapter.
- `apps/api/vercel.json` defines `/v1/**` routing, a 60-second function limit, and the `0 3 * * *` retention Cron.
- Cloudflare Worker, Wrangler, and Hyperdrive deployment integration are removed.
- Cloudflare Turnstile remains an API integration.
- Runtime traffic uses pooled `DATABASE_URL`; `DIRECT_URL` is isolated to migration/admin tooling.
- Bun, Node.js, and Vercel use the shared server-only Nodemailer SMTP composition.

## Security and PII evidence

- API/Web environment boundaries are tested and API-only secrets are excluded from Web runtime scope.
- Runtime environment loading strips migration/admin URLs, Web-only proxy aliases, database bootstrap credentials, and OIDC callback secrets.
- API responses default to `Cache-Control: no-store`.
- Request correlation IDs are restricted to opaque hex/UUID values; untrusted values are replaced with server-generated IDs.
- Request bodies, query values, cookies, authorization headers, PII, ciphertext, raw tokens, Secure Share material, and provider payloads are not logged.
- The Web proxy does not forward `Referer`.
- Secure Share Link secrets remain client-only.
