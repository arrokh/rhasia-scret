## Implemented architecture and hardening

- `apps/api` is a standalone Hono service with Bun as the primary runtime.
- `apps/api/src/node.ts` and `apps/api/dist/node.js` provide generic Node.js hosting.
- `apps/api/api/[...path].ts` provides the separate Vercel Node.js adapter.
- `apps/api/vercel.json` defines `/v1/**` routing, a 60-second function limit, and the `0 3 * * *` retention Cron.
- Cloudflare Worker, Wrangler, and Hyperdrive hosting integration are removed; Cloudflare Turnstile remains an API integration.
- Runtime traffic uses pooled `DATABASE_URL`; `DIRECT_URL` is isolated to migration/admin tooling.
- Bun, Node.js, and Vercel use the shared server-only Nodemailer SMTP composition.
- Request bodies, encrypted blobs, rotation arrays, and ciphertext payloads are bounded before parsing or persistence.
- Origin checks, trusted-proxy client-IP handling, unattributed rate limiting, request logging, cache headers, and API/Web environment isolation are covered by tests.
- Passwordless/PWA handoff, invitation onboarding, account deletion, Secure Share boundaries, and local-origin behavior preserve client-only secrets.
- Offline authenticator back navigation locks and clears the decrypted workspace before returning to sign-in.
- Browser suites allocate collision-free web/API ports by default and do not terminate unrelated processes.
