## Required exit conditions

The HOLD can change only after all of the following are attached to a new
dated readiness record:

1. #142, #144, #147, and #148 are complete or have explicit maintainer-owned,
   time-bounded exceptions.
2. #159 is merged, Dependabot confirms the five tracked alerts are closed, and
   the branch-protection required checks pass on the final merge commit.
3. A fresh root `pnpm run test:full` passes, followed by the native compilation,
   instrumentation, signed-device, verified-link, and store evidence.
4. Production authentication, database/TLS/backup/restore, deployment/cache/
   header, retention, monitoring, and incident-exercise artifacts are retained.
5. An independent cryptographic/security review records no unresolved
   Critical/High finding, or a maintainer explicitly accepts a documented
   time-bounded risk before release.
6. The maintainer signs off the candidate, then creates the annotated tag and
   GitHub Release described in [`release-process.md`](../release-process.md).
