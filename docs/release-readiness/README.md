# Release readiness records

This directory contains historical repository-release readiness records and separately maintained readiness snapshots.

General CI, the automated release PR, and publication do not generate or require a matching readiness record. Existing records remain scoped to their stated version, reviewed baseline SHA, and evidence timestamp. A `READY FOR HUMAN RELEASE REVIEW` decision is evidence from that snapshot; it does not prove publication or establish readiness for a later release or the current deployment.

Confirm publication through the exact-source GitHub Release and workflow provenance described in the [release process](../release-process.md). A local tag, the current branch position, or an older readiness record is not a substitute.
