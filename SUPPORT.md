# Support

Start with the [documentation index](docs/README.md) and the
[project support guide](docs/support.md). For a reproducible bug, use the
[bug report template](.github/ISSUE_TEMPLATE/bug_report.yml); for a feature or
documentation request, use the matching public template.

Do not put secrets, OTPs, QR data, Vault content, cookies, tokens, database
URLs, or authentication links in a public issue. Report vulnerabilities only
through [`SECURITY.md`](SECURITY.md) and the private
[GitHub Security Advisory form](https://github.com/arrokh/rhasia-scret/security/advisories/new).

If you use a self-hosted deployment, contact that deployment's operator for
account, deletion, provider, backup, or retention questions.
