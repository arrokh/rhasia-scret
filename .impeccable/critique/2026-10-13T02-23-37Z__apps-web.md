# apps/web UI/UX critique

Method: dual-agent

Source-based review of landing, sign-in, Local Vault, account directory, Vault management, recovery, import/backup, shared UI and previews. No installed app or committed screen captures were available. Rendered layouts, keyboard behavior and responsive geometry remain unverified. No application code changed.

## Design specificity and overall impression

The interface fits the product: Local versus hosted Vaults, deliberate account movement and recovery boundaries are explicit. Shared cards and controls provide cohesion. The biggest opportunity is clarity at high-stakes moments, not visual redesign.

## Priority issues

1. [P1] Successful Local restore appears as an error. local-vault-page.tsx:841–845 calls onError for successful and no-new-account results; line 167 maps it to danger. Users may repeat a successful operation. Separate success, informational no-op and failure outcomes. Suggested command: /impeccable harden.
2. [P1] Text contrast too low. public-information-page.tsx:58 gold links on globals.css background calculate approximately 1.94:1; app-ui.tsx:195–197,226 warning/offline text approximately 4.19:1, descriptions at 90% opacity approximately 3.55:1; totp-account-button.tsx:174–175 taupe badges approximately 3.07:1. These combinations miss 4.5:1 for normal text. Use darker text tokens and persistent link underlines, then verify rendered colors. Suggested command: /impeccable audit.
3. [P2] English dialogs retain Indonesian close labels. components/ui/dialog.tsx:64,95 and sheet.tsx:67 hard-code Tutup. Supply translated close labels through the shared component contract. Suggested command: /impeccable harden.
4. [P2] Important mobile actions lose visible labels. personal-vault-accounts.tsx:162–245 hides management, transfer, security and add labels below md. Accessible names exist, but sighted touch users must infer actions from icons. Keep concise labels or a labeled secondary menu and preserve 48px geometry. Suggested command: /impeccable adapt.
5. [P2] Local import has no visible review. local-vault-page.tsx:837–840 validates then imports immediately; vault-archive-importer.tsx:452–464 hosted summary shows only Vault name and count. Add client-only destination, account-summary and duplicate review before confirmation. Keep decrypted review data out of server state, analytics and Query caches. Suggested command: /impeccable onboard.

Paths above are under apps/web/src/modules/ unless components/ui or shared/presentation is specified. app-ui.tsx and styles/globals.css are under apps/web/src/shared/presentation.

## Cognitive load and persona red flags

First-time mobile users face unlabeled transfer/security actions. Users restoring under stress face immediate import followed by danger feedback. Low-vision users face weak link, warning-description and badge contrast. Directory filters enumerate every Vault and issuer without search at account-directory-controls.tsx:153–195: a scalability concern, not a demonstrated current-data failure.
